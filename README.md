## Project Purpose

The semester project will be a .NET Blazor web application. The application will be selected after comparing the proposals below and confirming the scope for the next group meeting.

## Project Proposals

### 1. CampusConnect

A student dashboard for organizing campus resources and activities.

- **Target audience:** College students and student organizations.
- **Core features:** Event listings, event search and filtering, reminders, organization profiles, and a simple RSVP workflow.
- **Estimated scope:** Medium. Start with public event CRUD and RSVP status; add authentication and reminders only if time allows.

### 2. Pantry Planner

A meal and grocery planning application that helps users use ingredients they already have.

- **Target audience:** Students, families, and anyone trying to reduce food waste.
- **Core features:** Pantry inventory, recipe search, weekly meal plan, shopping list generation, and ingredient expiration dates.
- **Estimated scope:** Medium. The first release can focus on inventory, recipes, and shopping lists without external recipe integrations.

### 3. NeighborFix

A lightweight issue-reporting application for apartment communities or neighborhoods.

- **Target audience:** Residents and property or community managers.
- **Core features:** Submit maintenance issues, attach a description, track status, add manager updates, and filter open or completed requests.
- **Estimated scope:** Small to medium. The main workflow is issue creation, assignment, status changes, and a dashboard.

### 4. TrailNotes

A personal outdoor activity journal for recording hikes and discovering local trails.

- **Target audience:** Hikers, walkers, and outdoor clubs.
- **Core features:** Trail records, distance and difficulty, personal trip notes, favorites, photos, and completion history.
- **Estimated scope:** Medium. Begin with trail CRUD and trip notes; maps and photo storage can be stretch goals.

## Initial Recommendation

`NeighborFix` has the clearest first release because its workflow is focused and demonstrates Blazor forms, validation, database persistence, filtering, and role-based views without requiring complex external APIs.
